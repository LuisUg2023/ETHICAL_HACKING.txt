# Evidencias de laboratorio

Guardar aquí capturas, logs y resultados de comandos, organizados por identificador de práctica.

Ejemplo:
```text
evidencias/
├── EH-01/
│   ├── dnsrecon-h4cker.txt
│   └── captura-dnsrecon.png
├── EH-02/
│   ├── dig-cisco.txt
│   ├── whois-ip.txt
│   └── ptr-resultados.txt
└── EH-04/
    ├── crtsh-h4cker.json
    ├── subdominios-ct.txt
    ├── sslscan-h4cker.txt
    └── certificado-openssl.txt
```

## Reglas
- Conservar la salida original siempre que sea seguro.
- Añadir fecha, comando y herramienta utilizada.
- Sanitizar tokens, contraseñas, datos personales y direcciones privadas.
- No subir archivos de terceros ni datos obtenidos fuera del alcance autorizado.
- No etiquetar una evidencia como real si es una captura ilustrativa o una salida de ejemplo.
- Para EH-04, distinguir registros históricos de Certificate Transparency de servicios activos.
- Ejecutar SSLScan y otras pruebas activas solo con autorización.
- Si se utiliza una simulación didáctica, etiquetarla claramente como hipotética y no almacenarla como evidencia real.
